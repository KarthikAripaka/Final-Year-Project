# Viva Presentation & Demo Script

## User Flow Demonstration Script (Step-by-Step)

### STEP 1: Admin Knowledge Upload & Approval
1. Open Admin Portal -> **Official Knowledge Base**.
2. Click **Upload New PDF Document**.
3. Title: "Academic Regulations 2026", Category: "REGULATION".
4. Document enters `READY_FOR_REVIEW`. Click **Preview Chunks** to view page-level vector chunks.
5. Click **Approve & Publish**. Status updates to `PUBLISHED`.

### STEP 2: Grounded RAG AI Assistant Query
1. Switch to Student Portal -> **AI Campus Assistant**.
2. Click suggested prompt: *"What is the attendance requirement for exams?"*
3. AI returns answer: *"Students must maintain a minimum attendance of 75%..."*
4. Click verified source citation: **Academic Regulations 2026 (Page 18)**.

### STEP 3: Placement Eligibility Check
1. Navigate to **Placements & Careers**.
2. View **Accenture Solutions** drive.
3. Observe **Deterministic Eligibility Breakdown**:
   - CGPA Cutoff (>= 7.5) -> Passed (Your CGPA: 8.65)
   - Department Allowed (IT) -> Passed
   - Backlog Count (0) -> Passed

### STEP 4: Skill Gap Analysis & 7-Day Roadmap
1. Navigate to **Skills & Learning**.
2. Select target role **Software Engineer** and click **Analyze Gaps**.
3. View Matrix: Strong Skills (Java, SQL, Git), Missing Skills (DSA, System Design).
4. Review custom **7-Day Personalized Learning Roadmap**.

### STEP 5: Gmail Intelligence & Voice Summarizer
1. Navigate to **Gmail Intelligence** -> View AI extracted deadlines and priority classification.
2. Navigate to **Voice Summarizer** -> Record / Upload audio -> View online STT transcript, executive summary, key points, and extracted action items.
